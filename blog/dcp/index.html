The meaning of Decode Context Parallel(DCP)

The main purpose of DCP is to split kv cache into differet GPUs in TP comm group in order to save memory in long-context situation. This feature is especially useful for GQA/MLA models which have small number of kv heads.

Two different designs: All-Gather + Reduce-Scatter vs All-to-All

Note that all the implementations above are used in decode phase. For prefill phase gather-kv is a more popular scheme.
